# Project Activity

Project Activity is a compact timeline of significant work across a project. It helps you see
what agents changed without opening every thread.

Open a project thread, open the right panel, and choose **Activity** from the add-surface menu.
The panel shows the newest events first and groups them by day.

The timeline includes:

- threads and turns starting or being interrupted;
- checkpoint results and changed-file summaries;
- agent errors, without prompts or raw provider output;
- Project Board item and status updates.

Select a thread-backed event to open its thread. Expand a checkpoint to inspect its changed files.
The panel keeps the latest 100 significant events for the current project.

Project Activity is available in the web and desktop clients.
