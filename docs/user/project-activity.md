# Project activity

Project activity is a timeline of significant work in a project. It shows what started, what changed, and what failed, without opening every thread.

Open a project's board. Activity sits at the bottom of that panel. The newest events come first and are grouped by day. The timeline keeps the latest 100 events from the threads you have used recently, plus board updates and handoffs.

The timeline includes:

- a thread being created
- a turn starting or being interrupted
- a checkpoint and a short summary of the files it changed
- a turn or checkpoint failing, without the prompt or the provider's raw output
- a board card changing status, and a handoff with its next step

Select an event that belongs to a thread to open that thread. Expand a checkpoint to see the changed files.

Activity is available in the web and desktop clients.
