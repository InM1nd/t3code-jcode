# Continuing a chat

When a chat has grown too long, open the command palette and choose **Hand off & continue in new thread**. The current agent writes a board handoff, then a fresh chat opens on the same branch and worktree. The new chat starts from the project board, not from the old transcript.

**Agent control**, in the sidebar header on web and desktop, lists chats that need you, chats still working, and recently completed ones. Dismissing an error archives that chat. The history stays in the archive.

On a new chat, **Choose worktree** picks the current checkout, a new worktree, or a worktree this project already used.

The mobile app keeps the standard new-chat flow. Agent control, handoff, and the worktree picker are on web and desktop.
